# ESLint extension for Zed

This extension adds support for [ESLint](https://github.com/eslint/eslint) in [Zed](https://zed.dev/).

Languages currently supported:

- **JavaScript**
- **TypeScript**
- **JSX**
- **TSX**
- **Vue.js**
- **Astro**
- **Svelte**

## Installation

Requires Zed >= **v0.131.0**.
